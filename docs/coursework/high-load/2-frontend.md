# Коміт 2: `max rate in ui`

Файли: `frontend/src/main.tsx`, `frontend/src/style.css`, ця нотатка. Збірка (`tsc` + `vite build`) проходить.

## Що змінилось

- Поле темпу: 10–100 000 док/с (було до 5000).
- Галочка **MAX**: темп `0`, без пауз між батчами. Є і при запуску, і для активного job.
- Статус «Скасовано» для нових скасованих job.

## Як працює

`RateField` показує число або MAX. Порожнє поле вважається незаповненим і не стає нулем, щоб випадково не ввімкнути MAX; кнопка тоді неактивна. Ті самі межі перевіряє API, тож обійти їх через UI не можна.

## Чого тут немає

- Графіка швидкості, стану шардів і повідомлення `degraded`: це етап 7.
- Кнопки скасування: поки лише з консолі (`cs_ops.py cancel`).
- Перевірки в браузері: запускав тільки збірку.
