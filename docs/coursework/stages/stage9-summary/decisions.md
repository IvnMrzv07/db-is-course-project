# Етап 9 — вибір конкретних СУБД

MongoDB обрано основним сховищем корпусу, PostgreSQL — сховищем стану імпорту. RabbitMQ є брокером повідомлень. Elasticsearch, Redis і Neo4j зберігаються в цільовому плані, але не запускаються на етапах 9–12. Шардування та партиціювання відкладено.

MongoDB має один учасник replica set для підтримки транзакцій, без додаткових реплік і без заяв про failover. Поточна схема — `docs/diagrams/modules.mmd`; цільова — `docs/diagrams/target-modules.mmd`. У старих рисунках stage5 виправлено застарілі технології та відображено реалізований зріз.
